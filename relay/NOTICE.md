# Credits and disclosure

Relay's original application code and visual design were created for this hackathon with substantial AI coding assistance from OpenAI Codex. Review and disclose that assistance in the event submission. The author/team must be able to explain the implementation and demonstrate it.

Runtime and UI dependencies include React, TypeScript, Vinext/Vite, Three.js, AWS Cedar WebAssembly, Zod, Radix UI, shadcn UI, Lucide and Sonner. Their own licenses remain applicable; package versions are pinned in `package-lock.json`. The bundled shadcn stylesheet license is retained in `vendor/`.

Fonts: DM Sans, Manrope, Instrument Serif and IBM Plex Mono, served by Google Fonts. Map data and tiles: © OpenStreetMap contributors; attribution remains visible in the geographic view. See https://www.openstreetmap.org/copyright.

Visual direction references requested by the user: https://www.doordennis.nl, https://ascension.pegassi.be and https://jesperlandberg.com. The project uses original interface code and a procedural response visualization; no portfolio images, brand assets or source code were copied from these sites.

Supplied incidents, responders and simulation cases are fictional. Local text triage is deterministic rule-based extraction. It is not generative AI, Amazon Bedrock, or a credibility model. The actual AWS component in the local version is the Cedar policy engine; no hosted Amazon Verified Permissions integration is claimed.

Original city artwork was generated with OpenAI’s built-in image-generation tool and optimized to WebP. The fictional city is an atmospheric illustration, not a photograph of Bengaluru or a live emergency feed. See docs/ARTWORK.md for the prompt and asset paths. Interface sounds are synthesized in the browser with Web Audio; no sound recordings are used.
