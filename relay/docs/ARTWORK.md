# Relay artwork and experience

- Generated using the **built-in imagegen tool**, not the API/CLI fallback.
- Project source: `public/relay-city-night.png` (1672 × 941).
- Optimized site asset: `public/relay-city-night.webp`.
- Original output: `C:/Users/salil/.codex/visualizations/2026/09/19/01a0b822-d81f-7a20-a3cb-fbad340ac3af/relay-city-night.png`.

Final prompt brief: **Cinematic 16:9 midnight navy aerial city, diagonal curving river, subtle cyan waterfront and amber streetlights, storm clouds and haze, dark left-third negative space, detail concentrated on right, photoreal, no text/logos/UI/visible devastation.**

The city is fictional. It does not depict a verified location, current weather or an actual incident. The interface labels it as an illustrative city with sample reports.

The image moves through slow camera drift, pointer parallax and subtle reflected light. It is an animated image treatment, not generated video or a live camera stream.

## Identity and motion

The original SVG mark combines a response beacon with a wave. It is used in the header, footer and favicon. The palette uses midnight navy, ice cyan and warm amber for urgent incidents.

Page navigation has three selectable transitions: tidal wave, ember dissolve and soft fade. The old view leaves, the transition covers it, and the destination appears. Transitions finish in about one second. The global motion setting and device reduced-motion preference bypass these effects.

Sound is off by default and activated by a user gesture. Brief Web Audio tones distinguish taps, successful actions and blocked actions; navigation uses a low-volume filtered whoosh. No continuous audio or external audio files are used. Preferences are stored locally under `relay-experience-v1`.
